🧭 Quick API reference X-API-Key required

  • POST/api/shortencreate a link
  • GET/api/links?limit&offsetlist (paginated)
  • GET/api/stats/{code}total clicks
  • GET/api/stats/{code}/dailyper-day series
  • GET/api/stats/{code}/referrers?dayssources in window
  • GET/api/stats/devices?daysdevice mix · &exclude_bots
  • GET/api/stats/tags?daysclicks per tag rollup
  • GET/api/stats/compare?codes=a,bside-by-side compare
  • POST/api/tags/renamerename / merge a tag
  • DELETE/api/tags/{tag}strip a tag everywhere
  • POST/api/links/{code}/archivesoft-delete (410 on redirect)
  • POST/api/links/{code}/restoreundo archive
  • POST/api/links/bulk-actionarchive / restore / delete ×100
  • GET/{code}redirect 302
  • GET/{code}/qr?format&size&fg&bgQR · recolourable
  • GET/s/{code}public stats page
  • DELETE/api/links/{code}remove link

With Redis on, POST /api/shorten answers with X-RateLimit-* headers and Retry-After on 429.

Full schemas at /docs · Postman collection in the repo.
