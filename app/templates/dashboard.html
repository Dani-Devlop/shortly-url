🧭 Quick API reference X-API-Key required

  • POST/api/shortencreate a link
  • GET/api/links?limit&offsetlist (paginated)
  • GET/api/stats/{code}total clicks
  • GET/api/stats/{code}/dailyper-day series
  • GET/api/stats/{code}/referrers?dayssources in window
  • GET/api/stats/devices?daysdevice mix
  • GET/{code}redirect 302
  • GET/{code}/qr?format=svg|pngQR code
  • DELETE/api/links/{code}remove link

With Redis on, POST /api/shorten answers with X-RateLimit-* headers and Retry-After on 429.

Full schemas at /docs · Postman collection in the repo.
